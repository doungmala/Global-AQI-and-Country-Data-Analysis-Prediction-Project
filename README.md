# Global-AQI-and-Country-Data-Analysis-Prediction-Project

Global AQI and Country Data Analysis / Prediction Project

โปรเจกต์นี้เป็นการพัฒนาสคริปต์ภาษา Python สำหรับวิเคราะห์และพยากรณ์ค่าดัชนีคุณภาพอากาศ (AQI) พร้อมข้อมูลพิกัดทางภูมิศาสตร์ของประเทศต่าง ๆ 

โครงสร้างโปรเจกต์ (Project Structure)ภายในโปรเจกต์ประกอบด้วยไฟล์ข้อมูลและไฟล์สคริปต์หลักดังนี้:  

1. ไฟล์ข้อมูล (Dataset)AQI-and-Lat-Long-of-Countries.csv: ไฟล์ข้อมูลประเภท CSV ที่เก็บข้อมูลคุณภาพอากาศ (AQI) รวมไปถึงละติจูด (Lat) และลองจิจูด (Long) ของประเทศต่าง ๆ

2. ไฟล์สคริปต์ Python (Python Scripts)test.py: สคริปต์สำหรับทดสอบการโหลดข้อมูล, จัดการข้อมูลเบื้องต้น (Data Preprocessing) หรือทดลองรันคำสั่งพื้นฐาน

   test2.py: สคริปต์เพิ่มเติมสำหรับการทดลองประมวลผลข้อมูลหรือวิเคราะห์สถิติต่าง ๆ
   testpredict.py: สคริปต์หลักสำหรับการสร้างโมเดลหรือทดสอบการพยากรณ์ (Prediction) ค่า AQI จากชุดข้อมูล

ความต้องการของระบบ (Prerequisites)
ก่อนเริ่มใช้งานคุณควรติดตั้งไลบรารีพื้นฐานสำหรับการวิเคราะห์ข้อมูลและแมชชีนเลิร์นนิง

Python 3.x

Pandas

NumPy

Scikit-learn (หรือไลบรารีที่ใช้ในการพยากรณ์)
